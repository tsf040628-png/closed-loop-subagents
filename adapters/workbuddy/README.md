# WorkBuddy Bridge

Use WorkBuddy's supported Skill marketplace or local Skill-package import. Confirm whether the user means WorkBuddy desktop, WorkBuddy Enterprise, CodeBuddy, or Managed Agents; these surfaces do not share one installation and model-configuration contract.

Ask which role models and escalation model are available on the selected surface. Verify independent subagent dispatch before claiming the Reviewer is independent. If the surface supports Skill import but not native role dispatch, use [manual-role-bridge.md](manual-role-bridge.md). The user acts as Controller and carries versioned artifacts between separate contexts. Label each review `MANUAL_REVIEW`; this is a human-operated bridge, not automatic orchestration or a runtime-verified native dispatch.
